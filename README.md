# نظام تسجيل الغياب

موقع بسيط لتسجيل غياب الطلاب، يعمل بالكامل على **GitHub Pages** ويستخدم
**Google Sheets** كقاعدة بيانات عبر **Google Apps Script**. لا حاجة لأي خادم
أو استضافة مدفوعة.

## المكوّنات

- `index.html` + `js/teacher.js` — صفحة المعلم لتسجيل الغياب.
- `admin.html` + `js/admin.js` — لوحة الإدارة (تقارير، إحصائيات، إدارة الصفوف والطلاب).
- `apps-script/Code.gs` — الكود الذي يُنشر داخل Google Sheets ليكون بمثابة خادم API.
- `js/config.js` — مكان وضع رابط الخادم (Apps Script) ورمز دخول الإدارة.

## خطوات الإعداد

### 1) إنشاء جدول جوجل شيت
1. أنشئ Google Sheet جديد فارغ على حسابك.
2. من القائمة: **Extensions → Apps Script**.
3. احذف أي كود موجود، والصق محتوى ملف `apps-script/Code.gs` كاملاً.
4. من القائمة العلوية في محرر Apps Script اختر الدالة `setup` ثم اضغط **Run**
   (سيطلب منك صلاحيات — اقبلها). هذا سينشئ الأوراق التالية تلقائياً:
   - **الصفوف** (فيها صف تجريبي واحد)
   - **الطلاب** (فيها 3 طلاب تجريبيين)
   - **سجل الغياب** (فارغة، تُملأ تلقائياً عند الحفظ)
   - **المعلمون** (فارغة — أضف أسماء المعلمين هنا يدوياً، أو من لوحة الإدارة)
   - **الإعدادات** (فيها اسم المدرسة ورمز دخول الإدارة، يمكنك تعديلهما مباشرة)

### 2) نشر الكود كتطبيق ويب
1. من محرر Apps Script: **Deploy → New deployment**.
2. اختر نوع النشر **Web app**.
3. اضبط:
   - **Execute as:** Me
   - **Who has access:** Anyone
4. اضغط **Deploy**، وانسخ الرابط الناتج (ينتهي بـ `/exec`).

> عند أي تعديل لاحق على `Code.gs`، يجب عمل **Manage deployments → Edit → New version**
> حتى يُطبَّق التعديل على الرابط المنشور. **مهم:** إذا كنت قد نشرت نسخة سابقة من
> هذا النظام، يجب استبدال `Code.gs` بالنسخة الجديدة الكاملة في هذا المجلد ثم
> عمل "New version" حتى تعمل ميزات مثل متابعة التسليم واللصق الجماعي والعذر/الملاحظة.

### 3) ربط الموقع بالخادم
افتح `js/config.js` وضع الرابط الذي نسخته:

```js
const APPS_SCRIPT_URL = 'https://script.google.com/macros/s/XXXXXXXX/exec';
```

يمكنك أيضاً تغيير رمز دخول الإدارة الافتراضي `ADMIN_PIN_FALLBACK` (يُستخدم فقط
إذا تعذّر الاتصال بالخادم؛ الرمز الفعلي يُقرأ من ورقة **الإعدادات** في الشيت).

### 4) النشر على GitHub Pages
1. أنشئ مستودع (Repository) جديد على GitHub وارفع محتويات هذا المجلد بالكامل.
2. من إعدادات المستودع: **Settings → Pages**.
3. اختر المصدر (Source) الفرع الرئيسي `main` والمجلد `/ (root)`.
4. بعد دقيقة أو دقيقتين سيكون الموقع متاحاً على رابط مثل:
   `https://username.github.io/repo-name/`

> **تنبيه مهم إذا كنت قد أعددت الجدول سابقاً بنسخة قديمة:** أصبح كل صف الآن
> مكوّناً من مستويين — **الصف** (المرحلة، مثل "الصف الخامس") و**الشعبة**
> (مثل "01" أو "أ") — بدلاً من اسم واحد فقط، حتى تقدر تصفّي التقارير حسب
> مرحلة كاملة أو شعبة واحدة أو المدرسة كلها. هذا غيّر أعمدة ورقتي **الصفوف**
> و**سجل الغياب**. إن كنت قد شغّلت `setup()` من قبل بنسخة قديمة:
> - إن لم تكن قد أدخلت بيانات حقيقية بعد: احذف ورقتي "الصفوف" و"سجل الغياب"
>   بالكامل من الجدول، ثم شغّل `setup()` من جديد فتُنشئان بالبنية الجديدة.
> - إن كان لديك بيانات حقيقية: أضف يدوياً عموداً باسم "الشعبة" بجانب عمود
>   "اسم الصف" في ورقة "الصفوف" (وسمِّ العمود القديم "الصف")، وأضف عمود
>   "الشعبة" بعد عمود "معرف الصف" في ورقة "سجل الغياب".

> **تنبيه إضافي لمن أعدّ الجدول سابقاً:** أُضيفت الآن ثلاث أوراق جديدة —
> **السلوكيات**، **أنواع السلوك**، **نقاط الطلاب** — بالإضافة لسطر إعداد جديد
> في ورقة **الإعدادات** باسم "الحد الأقصى للنقاط لكل معلم". إن كنت قد شغّلت
> `setup()` من قبل، فهذه الأوراق **لن تُنشأ تلقائياً** لأن `setup()` لا يعيد
> كتابة رؤوس أوراق موجودة مسبقاً — لكنه سيُنشئ أي ورقة **مفقودة بالكامل**.
> أسهل طريقة: شغّل `setup()` مرة أخرى بعد لصق الكود الجديد؛ ستُنشأ الأوراق
> الثلاث الجديدة تلقائياً بينما تبقى بياناتك الحالية في الأوراق الأخرى كما هي.

### 5) الاستخدام
- **صفحة المعلم** (`index.html`): يختار المعلم اسمه والصف والتاريخ، تظهر له
  قائمة الطلاب فيسجّل حالة كل طالب (حاضر / غائب / متأخر / مستأذن) ثم يحفظ.
  كل تعديل لاحق لنفس اليوم يُحدّث السجل بدلاً من تكراره، ويظهر اسم آخر معلم
  عدّل السجل ووقت التعديل. زر **"لوحة الإدارة"** بارز أعلى الصفحة (يمين الغلاف).

- **لوحة الإدارة** (`admin.html`): محمية برمز دخول بسيط (من ورقة الإعدادات)،
  وتنقسم إلى لوحة جانبية بخمسة أقسام:
  - **نظرة عامة**: إحصائيات اليوم وحالة التسليم دفعة واحدة عند فتح اللوحة (بلا انتظار).
  - **متابعة التسليم**: أي الصفوف سلّمت غياب اليوم (أو أي تاريخ تختاره) وأيها لا يزال بانتظار التسليم، مع اسم آخر معلم سجّل ووقته.
  - **الصفوف والطلاب**: إضافة شعبة جديدة (بإدخال الصف/المرحلة ثم الشعبة)، إضافة معلم واحد أو **لصق قائمة معلمين دفعة واحدة من إكسل** مع إمكانية حذف أي معلم، وإضافة طالب واحد أو **لصق قائمة طلاب كاملة من إكسل دفعة واحدة** (اسم في كل سطر) مع حذف أي طالب من القائمة.
  - **السجلات والتقارير**: تصفية بالاسم/الحالة/التاريخ، وبشكل منفصل بـ**الصف (المرحلة)** و**الشعبة** — اختر مرحلة فقط لرؤية كل شعبها معاً، أو مرحلة + شعبة لرؤية شعبة واحدة، أو اتركهما فارغين لرؤية المدرسة كلها. بطاقات إحصائية قابلة للنقر للتصفية السريعة (اضغط "غائب" لعرض الغائبين فقط)، والجدول مرتّب تلقائياً بحيث يظهر الغياب أولاً. لكل صف حقل **عذر/ملاحظة** قابل للتعديل والحفظ مباشرة. زر **طباعة** يفتح تقريراً منسّقاً مرتباً حسب التاريخ واليوم، بتظليل مختلف لكل شعبة لتمييز انتماء كل طالب.
  - **الإحصائيات**: رسمان بيانيان (نسبة الحالات، ومقارنة الغياب بين الصفوف) لنفس نطاق السجلات والتقارير.

- **صفحة المعلم — السلوك والنقاط**: أسفل حالة كل طالب في صفحة الغياب زرّان إضافيان:
  - **📋 سلوك**: يفتح لوحة صغيرة تحت اسم الطالب فيها آخر ملاحظاته، ثم يختار المعلم
    النوع (إيجابي 🙂 / سلبي 🙁)، فيظهر له قائمة سلوكيات جاهزة لهذا النوع (يمكنه تركها
    فارغة والاكتفاء بالملاحظة الحرة)، يكتب ملاحظة اختيارية، ويضغط "إرسال".
  - **🎟 نقطة**: يفتح لوحة تعرض رصيد المعلم المتبقي من كوبونات النقاط وسجل نقاط
    الطالب السابقة، مع حقل لكتابة سبب النقطة وزر "إرسال نقطة". يُعطَّل الزر تلقائياً
    إذا استنفد المعلم رصيده.

- **لوحة الإدارة — قسمان جديدان**:
  - **📋 السلوكيات**: عند فتح اللوحة يظهر تنبيه فوري إن وُجدت ملاحظات سلوكية جديدة
    اليوم (مع شارة عدّاد على الزر في القائمة الجانبية)، وقائمة مختصرة بآخرها في
    "نظرة عامة". القسم نفسه فيه تصفية بالاسم/الصف/الشعبة/النوع/التاريخ، بطاقات
    قابلة للنقر (اضغط "سلبي" لعرض السلبية فقط)، جدول مرتّب تلقائياً بحيث تظهر
    الملاحظات السلبية أولاً، لوحتا "الأكثر سلوكاً إيجابياً/سلبياً" ضمن التصفية
    الحالية، زر حذف لأي ملاحظة، وزر طباعة لتقرير منسّق (مفيد لطباعة سلوكيات طالب
    معيّن خلال فترة بالبحث باسمه) بتظليل مختلف لكل شعبة.
  - **🎟 النقاط**: حقل لضبط **الحد الأقصى للنقاط لكل معلم** (رقم عام يطبَّق على
    الجميع) مع جدول يوضح كم وزّع كل معلم وكم تبقى له، ولوحة صدارة تُجمّع نقاط كل
    طالب عبر كل الوقت (قابلة للتصفية بالصف/الشعبة/الاسم)، وسجل تفصيلي لكل نقطة
    مع إمكانية حذف أي منها.

## ملاحظات أمنية مهمة

- رمز دخول لوحة الإدارة حماية بسيطة على مستوى الواجهة فقط، وليست بديلاً عن
  التحكم الحقيقي بالصلاحيات. لأي حماية أقوى، قيّد الوصول إلى نسخة الموقع نفسها
  (مثلاً عبر رابط غير مُعلن، أو استضافة داخلية) أو أضف تحققاً إضافياً في `Code.gs`.
- بما أن التطبيق منشور بصلاحية "Execute as: Me"، فإن أي شخص يعرف رابط `/exec`
  يستطيع نظرياً استدعاء الدوال المتاحة فيه (قراءة/كتابة الغياب). حافظ على
  الرابط غير معلن، ويمكنك لاحقاً إضافة رمز API بسيط يُرسَل مع كل طلب ويُتحقق
  منه داخل `Code.gs` إذا أردت طبقة حماية إضافية.
- بيانات الطلاب والمعلمين تبقى بالكامل داخل جدول جوجل شيت الخاص بك، ولا تُخزَّن
  في أي مكان آخر.

## التخصيص

- الألوان والخطوط مُعرَّفة في `css/style.css` (متغيرات CSS أعلى الملف).
- حالات الحضور الافتراضية: حاضر / غائب / متأخر / مستأذن. يمكن تغييرها من خلال
  متغيّر `STATUSES` في `Code.gs` (وتُقرأ تلقائياً في صفحة المعلم).
- اسم المدرسة يُعدَّل من ورقة **الإعدادات** في جدول جوجل شيت مباشرة.
