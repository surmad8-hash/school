# نظام تسجيل الغياب

موقع بسيط لتسجيل غياب الطلاب، يعمل بالكامل على **GitHub Pages** ويستخدم
**Google Sheets** كقاعدة بيانات عبر **Google Apps Script**. لا حاجة لأي خادم
أو استضافة مدفوعة.

## المكوّنات

- `index.html` + `js/teacher.js` — صفحة المعلم لتسجيل الغياب.
- `admin.html` + `js/admin.js` — لوحة الإدارة (تقارير، إحصائيات، إدارة الصفوف والطلاب).
- `apps-script/Code.gs` — الكود الذي يُنشر داخل Google Sheets ليكون بمثابة خادم API.
- `js/config.js` — مكان وضع رابط الخادم (Apps Script) ورمز دخول الإدارة.

## خطوات الإعداد

### 1) إنشاء جدول جوجل شيت
1. أنشئ Google Sheet جديد فارغ على حسابك.
2. من القائمة: **Extensions → Apps Script**.
3. احذف أي كود موجود، والصق محتوى ملف `apps-script/Code.gs` كاملاً.
4. من القائمة العلوية في محرر Apps Script اختر الدالة `setup` ثم اضغط **Run**
   (سيطلب منك صلاحيات — اقبلها). هذا سينشئ الأوراق التالية تلقائياً:
   - **الصفوف** (فيها صف تجريبي واحد)
   - **الطلاب** (فيها 3 طلاب تجريبيين)
   - **سجل الغياب** (فارغة، تُملأ تلقائياً عند الحفظ)
   - **المعلمون** (فارغة — أضف أسماء المعلمين هنا يدوياً، أو من لوحة الإدارة)
   - **الإعدادات** (فيها اسم المدرسة ورمز دخول الإدارة، يمكنك تعديلهما مباشرة)

### 2) نشر الكود كتطبيق ويب
1. من محرر Apps Script: **Deploy → New deployment**.
2. اختر نوع النشر **Web app**.
3. اضبط:
   - **Execute as:** Me
   - **Who has access:** Anyone
4. اضغط **Deploy**، وانسخ الرابط الناتج (ينتهي بـ `/exec`).

> عند أي تعديل لاحق على `Code.gs`، يجب عمل **Manage deployments → Edit → New version**
> حتى يُطبَّق التعديل على الرابط المنشور.

### 3) ربط الموقع بالخادم
افتح `js/config.js` وضع الرابط الذي نسخته:

```js
const APPS_SCRIPT_URL = 'https://script.google.com/macros/s/XXXXXXXX/exec';
```

يمكنك أيضاً تغيير رمز دخول الإدارة الافتراضي `ADMIN_PIN_FALLBACK` (يُستخدم فقط
إذا تعذّر الاتصال بالخادم؛ الرمز الفعلي يُقرأ من ورقة **الإعدادات** في الشيت).

### 4) النشر على GitHub Pages
1. أنشئ مستودع (Repository) جديد على GitHub وارفع محتويات هذا المجلد بالكامل.
2. من إعدادات المستودع: **Settings → Pages**.
3. اختر المصدر (Source) الفرع الرئيسي `main` والمجلد `/ (root)`.
4. بعد دقيقة أو دقيقتين سيكون الموقع متاحاً على رابط مثل:
   `https://username.github.io/repo-name/`

### 5) الاستخدام
- **صفحة المعلم** (`index.html`): يختار المعلم اسمه والصف والتاريخ، تظهر له
  قائمة الطلاب فيسجّل حالة كل طالب (حاضر / غائب / متأخر / مستأذن) ثم يحفظ.
  كل تعديل لاحق لنفس اليوم يُحدّث السجل بدلاً من تكراره، ويظهر اسم آخر معلم
  عدّل السجل ووقت التعديل.
- **لوحة الإدارة** (`admin.html`): محمية برمز دخول بسيط (من ورقة الإعدادات)،
  وتعرض إحصائيات ونسبة حضور، وجدول تفصيلي قابل للتصفية حسب الصف والتاريخ
  وتصديره كملف CSV، بالإضافة لإضافة صفوف وطلاب ومعلمين جدد.

## ملاحظات أمنية مهمة

- رمز دخول لوحة الإدارة حماية بسيطة على مستوى الواجهة فقط، وليست بديلاً عن
  التحكم الحقيقي بالصلاحيات. لأي حماية أقوى، قيّد الوصول إلى نسخة الموقع نفسها
  (مثلاً عبر رابط غير مُعلن، أو استضافة داخلية) أو أضف تحققاً إضافياً في `Code.gs`.
- بما أن التطبيق منشور بصلاحية "Execute as: Me"، فإن أي شخص يعرف رابط `/exec`
  يستطيع نظرياً استدعاء الدوال المتاحة فيه (قراءة/كتابة الغياب). حافظ على
  الرابط غير معلن، ويمكنك لاحقاً إضافة رمز API بسيط يُرسَل مع كل طلب ويُتحقق
  منه داخل `Code.gs` إذا أردت طبقة حماية إضافية.
- بيانات الطلاب والمعلمين تبقى بالكامل داخل جدول جوجل شيت الخاص بك، ولا تُخزَّن
  في أي مكان آخر.

## التخصيص

- الألوان والخطوط مُعرَّفة في `css/style.css` (متغيرات CSS أعلى الملف).
- حالات الحضور الافتراضية: حاضر / غائب / متأخر / مستأذن. يمكن تغييرها من خلال
  متغيّر `STATUSES` في `Code.gs` (وتُقرأ تلقائياً في صفحة المعلم).
- اسم المدرسة يُعدَّل من ورقة **الإعدادات** في جدول جوجل شيت مباشرة.
